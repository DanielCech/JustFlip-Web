::: lede
JustFlip! vypadá jednoduše schválně: kartička, otočení, hodnocení. Pod
povrchem jsou doplňovačky, vysázená matematika, diagramy, mluvené
nápovědy, import z Anki, priority plánování, aplikace pro Watch a mnohem
víc. Tahle příručka tě provede vším — i drobnými pravidly, o která se
snadno zakopne.
:::
