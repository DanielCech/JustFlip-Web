::: lede
JustFlip! parece sencilla a propósito: una tarjeta, un giro, una
evaluación. Por debajo hay tarjetas de rellenar huecos, matemáticas bien
compuestas, diagramas, pistas habladas, importación desde Anki,
prioridades de programación, una app para el Watch y mucho más. Este
manual lo recorre todo, incluidas las pequeñas reglas con las que es
fácil tropezar.
:::
