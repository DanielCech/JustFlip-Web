# JustFlip!에 오신 것을 환영해요 {#welcome number="1"}

::: lede
JustFlip!은 기억력을 가진 플래시카드 앱이에요. 여러분이 한 대답을 하나도
빠짐없이 기억해 두었다가, 각 카드를 잊어버리기 직전에 다시 보여 줘요.
이 장에서는 라이브러리가 어떻게 구성되고 무엇이 어디에 있는지 보여 드려요.
그러면 2장에서 처음 복습할 때 낯설지 않을 거예요.
:::

::: inthischapter
- 간격 반복이 효과적인 이유를 한 문단으로
- 라이브러리를 관심사, 덱, 카드로 정리하기
- 직접 만들기, 스타터 덱 고르기, 가져오기로 첫 덱 마련하기
- 주요 화면 둘러보기
- 환영 투어와 앱 안의 가이드 다시 보기
- 무료로 쓸 수 있는 것, Pro로 추가되는 것, 구매 복원 방법
:::

## 한 문단으로 보는 핵심 아이디어 {#idea}

무언가를 다시 읽을 때보다 *머릿속에서 직접 꺼내야* 할 때 더 잘 기억하게
돼요. 그리고 그런 시도를 시간 간격을 두고 나누어 할수록 더 오래 남아요.
이것이 바로 **간격 반복**이에요. 카드에 답할 때마다 얼마나 잘 알았는지를
JustFlip!에 알려 주게 돼요. 잘 아는 카드는 며칠 뒤, 그다음엔 몇 주 뒤,
그리고 몇 달 뒤에 다시 나와요. 틀린 카드는 몇 분 안에 다시 돌아와요.
이미 아는 것이 아니라 곧 잊어버릴 것에 시간을 쓰게 되는 거죠. 간격이
어떻게 늘어나는지는 6장에서 다뤄요.

## 내 라이브러리 {#library}

배우는 모든 것은 세 단계로 된 라이브러리에 담겨요.

| 단계 | 무엇인가요 | 예시 |
|---|---|---|
| **관심사** | 고유한 아이콘이 있는 하나의 주제 | 스페인어 |
| **덱** | 관심사 안에서 한 가지에 집중한 카드 묶음 | 불규칙 동사 |
| **카드** | 질문 하나와 정답 하나 | *ir* → 가다 |

관심사에는 덱이 들어 있고, 덱에는 카드가 들어 있어요. 카드는 정확히 한
덱에만 속하지만, 언제든 다른 덱으로 옮길 수 있어요.

![관심사 화면: 맨 위에 오늘 패널이 있고, 그 아래로 아이콘, 덱 수, 숙련도와 함께 관심사가 표시돼요.](images/manual/{lang}/01-interests.jpg){.phone}

### 이름

::: gotcha
#### 관심사 이름은 느슨하게 비교돼요

JustFlip!은 대소문자, 악센트, 띄어쓰기만 다른 두 관심사 이름을 같은 것으로
취급해요. 이미 *Spanish*가 있는데 *spanish*를 만들면 두 번째 관심사는
생기지 않고, JustFlip!이 기존 관심사를 그대로 사용해요. 덕분에 두 기기가
동기화되기 전에 각자 같은 관심사를 따로 만드는 일이 생기지 않아요.
:::

덱 이름은 이렇게 확인하지 않기 때문에, 한 관심사 안에서 두 덱에 같은 이름을
붙여도 JustFlip!이 막지 않아요. 그래도 피하는 게 좋아요. 덱을 가져올 때
JustFlip!은 그 관심사 안에서 이름이 정확히 같은 덱에 카드를 추가하거든요.
이름이 같은 덱이 둘이면 어느 쪽에 카드가 들어갈지 확신할 수 없어요.
가져오기는 5장에서 자세히 설명해요.

### 순서 바꾸기

- **관심사.** [추가 또는 가져오기]{.ui} 메뉴(관심사 화면 맨 위의 트레이
  아이콘)를 열고 [순서 변경]{.ui}을 선택한 다음 행을 드래그하세요. 다 끝나면 [완료]{.ui}를
  탭하세요. 관심사 하나를 빠르게 맨 위로 올리려면 길게 누른 다음
  [맨 위로 이동]{.ui}을 선택하세요. VoiceOver로 순서를 바꿀 때도 이
  방법을 쓰면 돼요.
- **덱.** 덱 화면에서 폴더 메뉴를 열고 [편집]{.ui}을 선택한 다음, 덱을
  원하는 위치로 드래그하세요.
- **카드.** 덱 안에서 [추가 동작]{.ui} 메뉴(••• 버튼)를 열고
  [편집]{.ui}을 선택하세요. 드래그하는 동안에는 목록이 원래 순서로
  바뀌어요. 정렬된 목록은 손으로 순서를 바꿀 수 없기 때문이에요.

### 길게 눌러 더 보기

대부분의 동작은 **컨텍스트 메뉴**에 있어요. iPhone이나 iPad에서는 행을 길게
누르고, Mac에서는 오른쪽 클릭하세요.

| 대상 | 컨텍스트 메뉴에 있는 항목 |
|---|---|
| 관심사 | [관심사 편집]{.ui}, [맨 위로 이동]{.ui}, [카드 가져오기]{.ui}, [아카이브 내보내기]{.ui}, [통계 내보내기]{.ui}, [병합 대상]{.ui}, [삭제]{.ui} |
| 덱 | [덱 편집]{.ui}, [AI에게 질문]{.ui}(Pro), [관심사로 이동]{.ui}, [병합 대상]{.ui}, [덱 삭제]{.ui} |
| 카드 | [여기서부터 읽기]{.ui}(Pro), [카드 편집]{.ui}, [AI에게 질문]{.ui}, [덱으로 이동]{.ui}, [카드 졸업시키기]{.ui} 또는 [카드 다시 활성화]{.ui}, [삭제]{.ui} |

[병합 대상]{.ui}과 [관심사로 이동]{.ui}은 병합하거나 옮길 곳이 있을 때만
나타나요. 덱을 병합하면 그 덱의 카드가 모두 선택한 덱으로 옮겨지고, 비게
된 덱은 삭제돼요. 관심사 병합도 덱을 대상으로 똑같이 작동해요.

관심사 편집기와 덱 편집기에는 [학습 우선순위]{.ui}와
[기기 검색에 포함]{.ui} 스위치도 있어요. 우선순위는 6장에서, 기기
검색(Spotlight)은 8장에서 설명해요.

### 플래그와 태그

카드를 다시 찾을 때 도움이 되는 작은 도구가 두 가지 있어요. 둘 다 카드
편집기에서 설정해요(3장).

- **플래그**는 카드에 붙이는 색깔 표시 하나예요. 빨강, 주황, 초록, 파랑 중에서
  고를 수 있어요. 의미는 마음대로 정하면 돼요. 예를 들면 "선생님께 확인하기"처럼요.
- **태그**는 자유롭게 붙이는 단어이고, 한 카드에 원하는 만큼 붙일 수 있어요.
  [카드 검색]{.ui}(관심사 화면의 돋보기)은 라이브러리 전체에서 질문, 정답,
  *그리고* 태그까지 검색해요.

## 첫 덱을 마련하는 세 가지 방법 {#first-deck}

### 스타터 덱 고르기

라이브러리가 빈 상태로 JustFlip!을 처음 열면 **스타터 라이브러리**를
제안해요. 바로 쓸 수 있는 작은 덱 몇 개가 있고, 그중 몇 개는 이미 체크되어
있어요. 맨 위에서 덱의 언어를 고르고, 관심 있는 덱을 체크한 다음
[선택한 덱 추가]{.ui}를 탭하세요. 지금은 내키지 않는다면
[나중에]{.ui}를 눌러 닫으면 돼요.

이 제안은 한 번만 나타나지만, 라이브러리는 언제든 다시 열 수 있어요.
**설정 › 도움말 › 라이브러리**로 가세요. 더 많은 덱은
[just-flip.app/decks](https://just-flip.app/decks/)에서 둘러볼 수 있어요.

![스타터 라이브러리: 언어 선택기가 있고, 몇몇 덱이 이미 체크되어 있어요.](images/manual/{lang}/01-starter-library.jpg){.phone}

### 직접 만들기

1. 관심사 화면에서 [추가 또는 가져오기]{.ui} 메뉴를 열고
   [새 관심사]{.ui}를 선택하세요. 이름을 붙이고 아이콘을 고르세요.
2. 관심사를 연 다음 폴더 메뉴를 열고 [새 덱]{.ui}을 선택하세요.
3. 덱을 열고 ••• 메뉴를 연 다음 [카드 추가]{.ui}를 선택하세요.

카드에 담을 수 있는 모든 것은 3장에서 다뤄요.

### 가져오기

JustFlip!은 Anki 패키지(`.apkg`), CSV 스프레드시트, 그리고 자체 형식인
`.flashcards` 파일을 읽을 수 있어요. [추가 또는 가져오기]{.ui} 메뉴에서
[카드 가져오기]{.ui}를 선택하거나, 파일을 관심사 화면에 끌어다 놓으세요.
같은 메뉴의 [카드 붙여넣기]{.ui}는 복사한 목록(예: AI 채팅의 답변)을 덱으로
바꿔 줘요. [AI 프롬프트](https://just-flip.app/ai-prompt.html)나
[코딩 에이전트 스킬](https://just-flip.app/ai-skill.html)을 쓰면 AI에게 덱
전체를 만들어 달라고 할 수도 있어요. 이 모든 과정은 5장에서 차근차근
설명해요.

## 화면 둘러보기 {#tour}

iPhone에서는 왼쪽에서 오른쪽으로 이동해요. 관심사, 그다음 덱 목록, 그다음
덱의 카드 순서예요. iPad와 Mac에서는 같은 화면들이 나란히 놓여요(8장).

| 화면 | 여는 방법 | 용도 |
|---|---|---|
| **관심사** | 시작 화면 | 오늘 패널과 모든 주제 |
| **덱** | 관심사를 탭 | 한 관심사의 덱들. 숙련도와 카드 수, 관심사 전체 복습 메뉴 |
| **카드** | 덱을 탭 | 카드 목록. 카드를 뒤집어 훑어보고, 추가하고 편집하며, ▶ 버튼으로 덱 복습을 시작해요 |
| **테스트** | 복습 시작 | 한 번에 카드 한 장씩: 뒤집고, 평가하고, 다음으로 |
| **카드 검색** | 관심사 화면의 돋보기 | 라이브러리의 모든 카드와 태그 |
| **통계**(Pro) | 톱니바퀴 메뉴 › [통계]{.ui} | 시간에 따른 기억 유지율, 예측, 꾸준함(9장) |
| **설정** | 톱니바퀴 메뉴 › [설정]{.ui} | 복습 동작, 음성, 알림, 화면 모양, 데이터 보호 |
| **새로운 기능** | 톱니바퀴 메뉴 › [새로운 기능]{.ui} | 최근 추가된 기능 |

관심사 화면 맨 위의 **오늘** 패널에서 시작하면 돼요. 모든 관심사에서
기다리고 있는 카드가 몇 장인지 보여 주고, 탭 한 번으로 복습을 시작해요.
라이브러리에 카드가 생기면 바로 나타나요. 2장 전체가 이 패널에 관한
이야기예요.

![한 관심사의 덱 화면: 맨 위에 합계가 있고, 각 덱마다 숙련도 링, ▶ 복습 메뉴, 폴더 메뉴가 있어요.](images/manual/{lang}/01-decks.jpg){.phone}

::: tip
#### 링과 점

각 덱에는 **숙련도 링**이 있어요. 카드를 익힐수록 링이 채워져요. 안쪽의
점은 복습할 때가 다가올수록 따뜻한 색으로 바뀌어요. 점이 빛나면 그 덱이
관심을 기다리고 있다는 뜻이에요.
:::

## 온보딩과 가이드 {#guides}

JustFlip!을 처음 열면 짧은 **환영 투어**가 카드를 뒤집는 방법, 스와이프로
평가하는 방법, 간격 반복이 하는 일을 보여 줘요. 그 과정에서 보기 편한 글자
크기를 고를 수 있고, 마지막 페이지에서는 매일 복습 알림을 켤 수 있어요.
언제든 [건너뛰기]{.ui}를 눌러 넘어갈 수 있어요.

그 뒤로는 특정 화면에 처음 들어갈 때마다 그 자리에서 **가이드**가
나타나요. 가이드는 설명하는 컨트롤을 화살표로 가리키는 작은 카드예요.

| 위치 | 가이드가 설명하는 것 |
|---|---|
| 관심사 | 모든 관심사에서 복습할 카드를 복습하는 [복습 시작]{.ui} 버튼 |
| 테스트 | [기억 정도를 평가]{.ui}: 평가 버튼 |
| 덱 | [각 덱에서 더 보기]{.ui}: 덱을 길게 누르면 더 많은 동작이 나와요 |
| 통계 | [측정할 대상 선택]{.ui}: 관심사 선택기 |

각 가이드는 한 번만 나타나요. 다시 보고 싶다면:

- **설정 › 도움말 › 온보딩**에서 환영 투어를 다시 볼 수 있어요.
- **설정 › 도움말 › 가이드**는 모든 가이드를 초기화해서, 다음에 해당 화면에
  들어갈 때 다시 나타나게 해요.

## 무료와 Pro {#pro}

JustFlip!은 무료로 쓸 수 있고, 카드 수에 제한이 없어요. **JustFlip!
Pro**는 라이브러리의 두 가지 제한을 없애고, 몇 가지 강력한 기능을 열어
줘요.

| 기능 | 무료 | Pro |
|---|---|---|
| 관심사 | 3개 | 무제한 |
| 관심사당 덱 | 5개 | 무제한 |
| 카드 | 무제한 | 무제한 |
| 가져오기(CSV 포함) | ✓ | ✓ |
| iCloud 동기화 | ✓ | ✓ |
| 카드 한 장에 대해 AI에게 질문 | ✓ | ✓ |
| 덱 전체에 대해 AI에게 질문 | — | ✓ |
| 백그라운드 듣기(카드 읽어주기) | — | ✓ |
| 통계 | — | ✓ |
| 진행 트래커 | — | ✓ |
| 스마트 스케줄(베타) | — | ✓ |

제한은 관심사나 덱을 만들 때, 그리고 이미 덱이 다섯 개인 관심사로 덱을 옮길
때 적용돼요. Pro 전용 항목은 절대 숨겨지지 않아요. 작은 자물쇠가 붙어
있고, 탭하면 Pro 화면이 열려 무엇이 열리는지 설명해 줘요.

요금제를 보려면 **설정 › Pro 기능**으로 가세요. 세 가지가 있어요.
[월간]{.ui}, [연간]{.ui}, 그리고 한 번만 결제하는 [평생 이용]{.ui}이에요.
이용할 수 있는 무료 체험이 있는 요금제라면 Pro 화면에서 그 아래에
[무료 체험 이용 가능]{.ui}이라고 표시돼요.

### 구매 복원하기

다른 기기에서 Pro를 구입했거나 앱을 다시 설치했나요? **설정 ›
Pro 기능**을 열고 [구매 복원]{.ui}을 탭하세요. Pro를 구입할 때 쓴 것과
같은 Apple 계정을 사용하세요. 아무것도 찾지 못하면 JustFlip!이 [이전 구매
내역을 찾을 수 없습니다.]{.ui}라고 알려 줘요.

::: note
#### 고객 지원에 문의할 때

**설정 › 계정**에서 [앱 사용자 ID]{.ui}와 [ID 복사]{.ui} 버튼을 볼 수
있어요. 구매 관련 문의를 하면 지원팀에서 이 ID를 물어볼 수 있어요.
:::

## 삭제, 그리고 되살리기 {#deleting}

관심사, 덱, 카드는 각각의 컨텍스트 메뉴에서 삭제해요. 관심사를 삭제하면
그 안의 모든 것이 함께 사라져요. 모든 덱, 모든 카드, 그리고 모든 학습
진행 상황까지요.

::: gotcha
#### 삭제는 되돌릴 수 없어요

삭제한 관심사, 덱, 카드는 모든 기기에서 즉시 사라져요. 나중에 되살리고
싶을 수도 있는 관심사를 삭제하기 전에는 컨텍스트 메뉴에서 [아카이브
내보내기]{.ui}를 선택하세요. 아카이브에는 덱, 카드, 진행 상황이 그대로
담기고, 나중에 다시 가져올 수 있어요.
:::

**설정 › 데이터 보호 › 최근 삭제된 항목**에는 JustFlip!이 따로 보관해 둔
관심사와 덱이 있어요. 예를 들면 병합 후에 남은 빈 사본 같은 것들이에요. 각
항목은 **30일** 동안 그곳에 머물며, [복원]{.ui}으로 되살리거나
[삭제]{.ui}로 완전히 지울 수 있어요.

JustFlip!은 라이브러리를 자동으로 백업하기도 해요. 백업, 복원, 내보내기는
10장에서 다뤄요.

::: tip
#### 삭제 대신 졸업시키기

너무 잘 알아서 시간만 잡아먹는 카드가 있나요? 삭제하지 말고 **졸업**시키세요.
졸업한 카드는 복습에서 빠지지만 기록은 그대로 남고, 원할 때 언제든 다시
불러올 수 있어요. 방법은 2장에서 보여 드려요.
:::
