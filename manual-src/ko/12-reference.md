## 문제 해결 {#troubleshooting}

### 카드와 복습

| 보이는 현상 | 해결 방법 | 장 |
|---|---|---|
| 카드가 소리 내어 읽히지 않아요 | 면의 [언어]{.ui}를 설정하세요. 없음으로 설정된 면은 절대 읽히지 않아요 | 3, 7 |
| 언어를 설정했는데 재생 버튼이 없어요 | iOS **설정 › 손쉬운 사용 › 읽기 및 말하기 › 음성**에서 음성을 다운로드하세요 | 7 |
| 카드에 `{…}` 중괄호가 보여요 | 음성 힌트는 대괄호, 수식, 그림 뒤에서만 작동해요. 텍스트를 `[…]`로 감싸세요 | 3 |
| 뒤집은 뒤에 보통과 쉬움이 없어요 | **설정 › 동작 › 엄격한 평가**가 켜져 있어요. 끄거나, 뒤집기 전에 평가하세요 | 2 |
| 새 덱의 [복습할 카드]{.ui}에 아무것도 없어요 | 한 번도 학습하지 않은 카드는 아직 복습할 때가 아니에요. 오늘, [새 카드]{.ui}, [전체 카드]{.ui}를 쓰세요 | 2 |
| 다시를 준 카드가 같은 세션에 돌아오지 않았어요 | 의도된 동작이에요. 5분 뒤에 복습할 때가 되고, 다음 세션에 나와요 | 6 |
| 우선순위 슬라이더를 움직여도 복습할 카드 수가 그대로예요 | 의도된 동작이에요. 우선순위는 제한된 세션의 순서만 바꿔요 | 6 |
| 미룬 덱이 여전히 안 보여요 | 덱 화면 › [덱 옵션]{.ui} › [복습 우선순위]{.ui} › 재개 | 6 |
| 미룬 카드 한 장을 재개할 수 없어요 | 날짜가 되면 끝나요. 또는 [전체 카드]{.ui}에서 내일로 다시 미루세요 | 6 |
| 1–4 키나 스페이스가 작동하지 않아요 | 답을 입력 중이거나, 엄격한 평가가 켜져 있거나, 이미지 가리기 정답을 아직 드러내지 않았어요 | 8 |
| 긴 카드가 늘 시트로 열려요 | 큰 글자 크기에서는 카드가 맞춰 줄어들지 않아요. 카드를 나누거나 JustFlip!의 글자 크기를 낮추세요 | 11 |
| 알림이 오지 않아요 | **설정 › 알림 › 매일 복습 알림**을 켜고, iOS 설정에서 알림을 허용하세요 | 2 |
| 가이드가 더 이상 나타나지 않아요 | **설정 › 도움말 › 가이드**에서 다시 보이게 할 수 있어요 | 1 |

### 그림, 소리, 편집

| 보이는 현상 | 해결 방법 | 장 |
|---|---|---|
| 다크 모드에서 그림이 사라져요 | 불투명한 흰색이나 밝은 배경을 넣으세요 | 4 |
| 가져온 뒤에 그림이 빠졌어요 | Anki 가져오기 보고서를 확인하세요. SVG는 지원하지 않아요 | 4, 5 |
| 그림이나 소리를 바꾼 뒤에 면의 텍스트가 사라졌어요 | 이미지나 오디오 탭에서 저장했어요. 저장하기 전에 텍스트 탭으로 돌아가세요 | 4 |
| 카드 읽어주기가 카드를 건너뛰어요 | 양면 모두에 텍스트와, 음성이 설치된 언어가 필요해요 | 7 |
| 듣기가 저절로 멈췄어요 | 전화나 다른 앱이 오디오를 가져갔어요. [여기서부터 읽기]{.ui}로 다시 시작하세요 | 7 |

### 가져오기

| 보이는 현상 | 해결 방법 | 장 |
|---|---|---|
| 카드가 행이나 노트 수보다 적어요 | 질문이 같은 카드가 합쳐졌거나(덱 파일), 질문이 없는 행을 건너뛰었어요(CSV) | 5 |
| 카드가 Anki 노트 수보다 많아요 | 클로즈 번호마다 카드가 한 장씩이에요. 정상이에요 | 5 |
| 덱이 두 번 나타났어요 | CSV는 항상 새 덱을 만들고, [새 사본 추가]{.ui}로 한 Anki 가져오기도 마찬가지예요 | 5 |
| 다시 가져온 뒤에 그림만 있는 카드가 두 배가 됐어요 | 짝을 맞출 질문이 없어서 그래요. 남는 카드를 지우세요 | 5 |
| 첫 카드가 "질문 / 정답"이에요 | [첫 번째 행을 머리글로 건너뛰기]{.ui}를 켜세요 | 5 |
| 모든 텍스트가 한 열에 들어가요 | CSV 미리보기에서 [구분 기호]{.ui}를 바꾸세요 | 5 |
| 가져온 뒤에 고친 내용이 사라졌어요 | 파일의 버전으로 바뀌었어요. 파일에서도 똑같이 고치세요 | 5 |
| 일정이 뒤로 돌아갔거나, 삭제한 카드가 돌아왔어요 | 예전 관심사 아카이브를 가져왔어요 | 5, 10 |
| 가져온 카드가 엉뚱한 덱에 들어갔어요 | 두 덱의 이름이 같아요. 하나의 이름을 바꾸세요 | 1 |
| 새 관심사가 나타나지 않았어요 | 같은 이름의 관심사가 이미 있어서 그걸 대신 썼어요 | 1 |

| 보이는 현상 | 해결 방법 | 장 |

| 백업 위치가 [로컬 전용]{.ui}이에요 | 내보낸 아카이브도 안전한 곳에 보관하세요 | 10 |

| 위젯에 예전 숫자가 표시돼요 | 그 기기에서 JustFlip!을 여세요. 위젯은 앱이 그 기기에 마지막으로 저장한 내용을 보여 줘요 | 8 |

| Spotlight에 카드가 안 나와요 | 관심사*와* 덱 모두에서 [기기 검색에 포함]{.ui}을 확인하고, 단어의 시작 부분으로 검색하세요 | 8 |
| JustFlip!이 다크 모드를 무시해요 | 테마가 라이트나 다크로 고정되어 있어요. [시스템]{.ui}을 고르세요 | 11 |
| 새로운 기능 시트가 비어 있어요 | 오프라인 상태예요. [다시 시도]{.ui}나 [브라우저에서 열기]{.ui}를 쓰세요 | 8 |

## 용어집 {#glossary}

| 용어 | 의미 |
|---|---|
| **관심사** | 라이브러리의 최상위 단계. 덱을 담는 주제 |
| **덱** | 관심사 안에서 한 가지에 집중한 카드 묶음 |
| **카드** | 질문 하나와 정답 하나. 각 면에 텍스트, 그림, 소리, 언어가 따로 있어요 |
| **오늘** | 모든 관심사의 복습할 카드와, 하루 한도까지의 새 카드를 모아 주는 관심사 화면의 패널 |
| **복습 예정** | 복습 시간이 되었고, 졸업시키지도 미루지도 않은 카드 |
| **새 카드** | 한 번도 학습하지 않은 카드 |
| **어려운 카드** | 복습일과 상관없이, 마지막 평가가 다시나 어려움인 카드 |
| **확인함** | 둘러보다가 카드를 처음 뒤집을 때 JustFlip!이 남기는 기록. 평가가 아니에요 |
| **간격** | 카드가 다시 돌아오기까지의 시간. 몇 분에서 몇 달까지 |
| **용이도** | 카드 간격의 고유한 성장률. 2.5에서 시작해 1.3과 3.5 사이에 머물러요 |
| **단계** | 미학습, 학습 중, 복습 중(간격 7일 이상), 졸업(30일 이상), 재학습 중 |
| **숙련도** | 마지막 평가가 보통이나 쉬움인 카드가 덱에서 차지하는 비율. 진행 트래커는 자기 진행도를 더해요 |
| **기억 유지율** | 보통이나 쉬움으로 평가한 복습의 비율 |
| **성숙 복습** | 간격이 이미 30일에 도달한 카드의 복습 |
| **망각** | 학습했다가 잊어버린 카드 |
| **거머리 카드** | 여덟 번 이상 잊어버린 카드. [자꾸 잊어버리는 카드]{.ui} 아래에 나와요 |
| **연속 기록** | 하루 한 번 이상 복습한 날이 이어진 일수. 빠진 날은 이틀까지 이어 줘요 |
| **예측** | 앞으로 날마다 복습할 때가 되는 카드 수. 밀린 카드는 오늘에 더해져요 |
| **긴급도** | 복습할 카드, 밀린 정도, 공부한 뒤 지난 시간, 숙련도를 섞어 낸 점수 |
| **졸업시키기** | 기록은 유지한 채 카드를 복습에서 빼기. 다시 활성화로 되돌려요 |
| **미루기** | 평가하지 않고 카드, 덱, 관심사를 정한 날까지 따로 빼 두기 |
| **복습 우선순위** | 제한된 세션에서 누구의 카드가 먼저 나올지 정하는 0~100 %의 비중(기본값 75 %) |
| **엄격한 평가** | 카드를 뒤집으면 다시와 어려움만 남기는 설정 |
| **스마트 스케줄** | 약 90 %의 기억률을 목표로 하는 FSRS-5 스케줄러(Pro, 베타) |
| **진행 트래커** | 플래시카드로 테스트할 수 없는 기술을 위해 0에서 100까지 스스로 평가하는 카드(Pro) |
| **클로즈** | `{{c1::…}}`로 쓰는 빈칸 채우기 카드 |
| **음성 힌트** | 카드의 일부 뒤에 붙여 음성이 대신 말할 내용을 알려 주는 `{…}` |
| **첨부 표시자** | 텍스트 안에 그림을 배치하는 `![attachment:0]` |
| **이미지 설명** | VoiceOver가 그림 대신 읽는 텍스트 |
| **이미지 가리기** | 여러 영역이 가려진 그림. 영역마다 카드가 한 장씩 돼요 |
| **카드 읽어주기** | 덱 전체를 손을 쓰지 않고 듣기: 질문, 4초 멈춤, 정답, 차임(Pro) |
| **자동 음성** | 한 언어로 설치된 가장 좋은 음성: 프리미엄, 그다음 향상됨, 그다음 표준 |
| **AI에게 질문** | JustFlip!이 만들어 주는 학습 보고서 프롬프트. 내가 쓰는 AI 채팅에 붙여 넣어요 |
| **가이드** | 컨트롤을 설명하는 일회성 안내. **설정 › 도움말 › 가이드**에서 다시 볼 수 있어요 |
| **스타터 라이브러리** | 처음 실행할 때, 그리고 **설정 › 도움말 › 라이브러리**에서 제공하는 바로 쓸 수 있는 덱 |
| **관심사 아카이브** | 관심사 하나를 진행 상황과 함께 내보낸 `.flashcards.zip` |
| **전체 백업** | 라이브러리 전체를 담은 주간 `.justflip` 아카이브. 최신 10개를 보관해요 |
| **진행 스냅샷** | 미디어를 뺀 진행 상황의 일일 백업. 최신 30개를 보관해요 |
| **기기 검색에 포함** | 카드가 Spotlight에 나타날지 정하는 관심사와 덱의 스위치 |

## 무료와 Pro {#free-pro}

JustFlip!은 무료로 쓸 수 있고, 카드 수에 제한이 없어요. Pro는 라이브러리의 두 가지 제한을
없애고 몇 가지 강력한 기능을 더해요. 무료 체험이 제공되는 경우, 체험 기간 동안 Pro 기능을
쓸 수 있어요.

| 기능 | 무료 | Pro | 장 |
|---|---|---|---|
| 관심사 | 3개 | 무제한 | 1 |
| 관심사당 덱 | 5개 | 무제한 | 1 |
| 카드, 서식, 그림, 소리, 이미지 가리기 | ✓ | ✓ | 3, 4 |
| 가져오기와 내보내기(Anki, CSV, 덱 파일, 아카이브) | ✓ | ✓ | 5 |
| 복습, 우선순위, 미루기, 졸업시키기 | ✓ | ✓ | 2, 6 |
| 재생 버튼과 음성 고르기 | ✓ | ✓ | 7 |
| Apple Watch, 위젯, Siri, Spotlight | ✓ | ✓ | 8 |
| iCloud 동기화, 백업, 복원 | ✓ | ✓ | 10 |
| 테마와 글자 크기 | ✓ | ✓ | 11 |
| 카드나 세션에 대해 AI에게 질문 | ✓ | ✓ | 9 |
| 덱 전체에 대해 AI에게 질문 | — | ✓ | 9 |
| 카드 읽어주기와 백그라운드 듣기 | — | ✓ | 7 |
| 통계 | — | ✓ | 9 |
| 진행 트래커 | — | ✓ | 6 |
| 스마트 스케줄(베타) | — | ✓ | 6 |

요금제, 구매, 복원은 1장에 있어요.

## 파일 형식 {#formats}

| 파일 | 담긴 것 | 만드는 곳 | 가져올 때 |
|---|---|---|---|
| `.flashcards` | 텍스트만 있는 덱 | AI, 덱 페이지, 직접 | 짝이 맞는 덱을 업데이트(질문 텍스트 기준) |
| `.flashcards.zip` | 그림과 소리가 있는 덱 — 또는 관심사 아카이브 | 코딩 에이전트 스킬, 덱 페이지, [아카이브 내보내기]{.ui} | 덱 파일은 질문 기준으로 업데이트하고, 아카이브는 진행 상황을 포함해 그 관심사를 복원 |
| `.apkg`, `.colpkg` | Anki 덱 또는 컬렉션 | Anki | 새 덱, 또는 이미 있는 것은 건너뛰기 / 업데이트 |
| `.csv` | 한 행에 카드 한 장 | 모든 스프레드시트 | 항상 새 덱 |
| `.flashcards-stats.csv` / `.json` | 읽기용 통계 | [통계 내보내기]{.ui} | 가져올 수 없음 |
