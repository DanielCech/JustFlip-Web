# 統計と「AIに聞く」 {#statistics-ask-ai number="9"}

::: lede
あなたが付けるひとつひとつの評価は、あなたの記憶についての小さな証拠です。JustFlip! はそのすべてを保存しています。この章では、その読み方を紹介します。毎日目にする数値、より詳しい統計画面、そして覚えていることと何度も間違えることを、好きなチャット AI への説明資料に変える「AIに聞く」です。
:::

::: inthischapter
- 期限のカード数、習熟度、連続記録を理解し、それぞれの計算方法を知る
- 定着率、アクティビティのヒートマップ、デッキのランキング、予測を読む
- 「よりよく学べている」と「単に多く復習している」を見分ける
- 「AIに聞く」の学習レポートで、ChatGPT、Claude、Gemini に的確に伝える
- 統計をスプレッドシートや完全な JSON データとして書き出す
:::

## 毎日目にする数値 {#everyday}

調子を知るのに統計画面は必要ありません。アプリのあちこちに 3 つの数値が表示され、どれも無料です。

| 数値 | 表示される場所 | 意味 |
|---|---|---|
| **期限** | 「今日」、デッキの行、カード一覧 | 次の復習日が来たカード |
| **習熟度** | コレクションとデッキの行 | *最新の*評価が「普通」か「簡単」だったカードの割合 |
| **連続記録** | 「今日」に「*N*日連続」と表示 | 1 回以上復習した日が続いた日数 |

### 期限

予定された復習日が過ぎたカードは期限を迎えます。「今日」は、すべてのコレクションの期限のカードと、その日に許される新しいカードを合計し、「約6分」のような予想時間を表示します。期限のカードがないとき、「今日」には [すべて完了]{.ui} と表示され、小さな [今後7日間]{.ui} の帯で明日の作業量がわかります。期限の決め方は第 6 章のテーマです。

### 習熟度

デッキの習熟度は、**最新の**評価が「普通」か「簡単」だったカードをすべて数え、デッキのカードの枚数で割ったものです。一度も復習していないカードも、まだ習熟していないものとして数えられるので、読み込んだばかりのデッキは 0 % から始まります。コレクションの習熟度はそのデッキの習熟度の平均で、デッキの大きさにかかわらず、どのデッキも同じ重みです。

::: note
#### 習熟度は上がりも下がりもします

最新の評価だけが数えられるので、習熟度は記念のトロフィーではなく、その時点のスナップショットです。先週覚えていたカードに「もう一度」を押すと、正解し直すまでそのカードは数えられなくなります。それが狙いです。この数値は、*今日*わかっていることを示します。
:::

### 連続記録

連続記録は、1 枚以上のカードを復習した日を数えます。1 枚で十分です。猶予の日もあります。今日まだ復習していなくても、今日が終わるまでは昨日までの連続記録が続いています。

JustFlip! は、たまに抜けた日には寛容です。現在の連続記録の中で、**2 日まで**の抜けは自動的につなぎ合わされるので、忙しい 1 日のせいで 1 か月続いた習慣が消えることはありません。つなぎ合わせた日自体は日数に加わりません。連続記録が途切れる前にお知らせがほしい場合は、**設定 › リマインダー** で [連続記録レスキュー]{.ui} をオンにします。その日にまだ復習していないとき、夜に 1 回リマインダーが届きます。

## 統計を開く（Pro） {#opening}

統計画面全体は **Pro** の機能です。「コレクション」の一覧の上部にある [設定]{.ui} メニュー（歯車のアイコン）を開き、[統計]{.ui} を選びます。Pro がない場合、メニューの項目には鍵が付き、代わりに Pro の画面が開きます。Pro の無料トライアルでも使えるようになります。

![統計画面：コレクションの選択、4 つの概要タイル、コレクションの段階。](images/manual/{lang}/09-statistics-overview.jpg){.phone}

統計は常に**一度に 1 つのコレクション**を対象にします。上部の [範囲]{.ui} で選びます。その下にあるものは、概要タイルから予測まで、すべてそのコレクション内のデッキの合計です。そのおかげで、数値を時間の経過とともに比較しやすくなります。2 つの分野を比べるには、選択を切り替えてください。

復習すると画面は自動で更新されるので、iPad や Mac で学習セッションの横に開いたままにしておけます。

### 概要タイル

| タイル | 表示内容 |
|---|---|
| [成熟カードの定着率]{.ui} | [過去30日間]{.ui} に*成熟*カードを思い出せた割合（[定着率](#retention)を参照） |
| [復習]{.ui} | 今日を含む [過去7日間]{.ui} の復習の回数 |
| [現在の連続記録]{.ui} | このコレクションでの連続記録と、これまでの最長記録 |
| [現在の期限]{.ui} | 今期限のカードと、明日期限を迎えるカードの枚数 |

ここでの連続記録は「今日」と同じ方法で計算されますが、選択したコレクションでの復習だけが対象です。すべてのコレクションを数える「今日」の連続記録より短くなることがあります。

### コレクションの段階

[コレクション]{.ui} の下では、コレクション内のすべてのカードが 4 つの段階のいずれかに分類されます。

| 段階 | 説明 | 意味 |
|---|---|---|
| [新規]{.ui} | これから学ぶ | 一度も復習していない |
| [学習中]{.ui} | 記憶を構築中 | 学習中、または忘れたあとの再学習中 |
| [復習中]{.ui} | 定着を強化中 | 通常の復習サイクルの中にある |
| [卒業]{.ui} | 習得済み | 間隔が 30 日以上 |

健全なコレクションは、何週間かかけて右へと移っていきます。カードが段階を移る仕組みは第 6 章で説明しています。

::: gotcha
#### 「現在の期限」は「今日」と同じではありません

[現在の期限]{.ui} は、後回しにしたカードも含め、復習日が過ぎたコレクション内の**すべての**カードを数えます。「今日」は 1 回のセッションに収まる分だけを出します。後回しにしたカードは除かれ、残りも [1回あたりのカード数]{.ui} と [1日の新規カード数]{.ui} で制限されます。「現在の期限」が多いのに「今日」のセッションが短いのは正常で、不具合ではありません。
:::

## 定着率：全体と成熟カード {#retention}

定着率が答える問いはひとつです。*カードが出てきたとき、思い出せたか？* **「普通」か「簡単」**と評価した復習は、思い出せたものとして数えられます。「もう一度」と「難しい」は、どちらも思い出せなかったものとして数えられます。
<!-- VERIFY: whether a "Seen" response is stored as a review and so also counts as not remembered in retention, reviews and streaks. -->

[成熟カードの定着率]{.ui} のグラフは、その割合を日ごとに描きます。期間はセグメントコントロールで選びます：[7D]{.ui}、[30D]{.ui}、[90D]{.ui}、[All]{.ui}。

![90 日間の定着率のグラフ。各点は、その日の成熟カードの復習で思い出せた割合です。](images/manual/{lang}/09-retention-chart.jpg){.shot width=80%}

大事なのは**成熟**という言葉です。回答する前にカードの間隔が**30 日以上**に達していた場合、その復習は成熟とみなされます。新しいカードは「思い出す」のが簡単です。1 分前に見たばかりだからです。1 か月前に最後に見たカードこそが長期記憶の本当のテストで、成熟の線が示すのはそれです。

最初の数週間は、まだ成熟した復習がありません。その場合グラフは**全体の定着率**（すべてのカードのすべての復習）を代わりに表示し、下の説明にもそう書かれます：「すべての復習を表示中 — 成熟シグナルはカードが30日の間隔に達すると表示されます。」最初のカードが 30 日の線を越えると、グラフは自動で成熟シグナルに切り替わります。期間内に復習がまったくない場合は、[成熟した復習がまだ十分ではありません]{.ui} と表示されます。

::: tip
#### 点ではなく傾向を読む

1 日の値は、3 回の復習だけで 60 % から 100 % まで振れることがあります。[30D]{.ui} か [90D]{.ui} を選び、線の形を見ましょう。80〜90 % 台で平らな線なら、スケジュールがきちんと機能しています。
:::

## 継続性：連続記録とヒートマップ {#consistency}

[継続性]{.ui} のセクションには、そのコレクションの [現在]{.ui} と [最長]{.ui} の連続記録が表示され、その下に**過去 12 週間**のヒートマップがあります。1 つのマスが 1 日を表し、期間中で最も復習した日を基準に、色が濃いほどその日の復習が多かったことを示します。今日のマスには小さな点が付きます。

![「継続性」のヒートマップ：12 週間分の復習日。復習が多い日ほどマスが濃くなります。](images/manual/{lang}/09-heatmap.jpg){.shot width=80%}

色ではなく、すき間と塊に注目しましょう。毎週日曜日の 1 時間より、毎日 10 分のほうが効果的です。間隔反復は、期限に近いタイミングでカードを見ることが前提だからです。

::: note
#### 「最長」が「現在」より短く見えることがあります

[最長]{.ui} は、これまでで最も長く*連続した*日数で、[現在]{.ui} を守る 2 日分のつなぎ合わせは含みません。そのため、抜けた日を乗り越えた現在の連続記録が、「最長」より長くなることがあります。どちらの数値も正しく、測っているものが少し違うだけです。
:::

## デッキの比較 {#deck-comparison}

[デッキの比較]{.ui} は、コレクション内のデッキを定着率でランキングし、**最も低いものを上**に表示します。このバーは過去 30 日間だけでなく、そのデッキでのこれまでのすべての復習を数えるので、ゆっくりとしか変わりません。グラフの下には、上位 4 つのデッキについて、今期限のカードの枚数と、失念（覚えていたカードをまた忘れた回数）の合計が表示されます。

いちばん上のデッキこそ、努力がいちばん報われる場所です。たいていは次の 3 つのどれかを意味しています。

1. **カードがわかりにくい。** 答えが 2 つありうる、または 1 枚に詰め込みすぎ。直し方は第 3 章にあります。
2. **まだ学んでいないことの上に成り立つ内容。** これこそ [AIに聞く](#ask-ai) の出番です。
3. **急ぎすぎている。** 吸収できる以上の新しいカードを追加しています。しばらく [1日の新規カード数]{.ui} を減らしましょう。

## 今後の復習予測 {#forecast}

予測は、現在のスケジュールに基づいて、今後 [7D]{.ui} または [30D]{.ui} の各日に何枚のカードが期限を迎えるかを示す棒グラフです。すでに期限を過ぎているカードは今日のバーに加えられるので、たまった分が見えなくなることはありません。卒業済みのカードは除外されます。

大量の読み込みや、新しいカードの多い 1 週間のあとは、2 週間先に山ができるのが普通です。山が来るのが見えたら、分散させましょう。その前の数日に少し多めに復習します。

::: gotcha
#### 予測は今日のスケジュールしか知りません

評価を付けるたびにカードの期限は動くので、予測は約束ではなく見込みです。間違えたカードは早く戻ってくるので、明日はグラフより忙しくなります。
:::

## 数値を正直に読む {#reading}

頑張っている気がするのに、ほとんど身についていないということはよくあります。統計画面は、もっと難しい問いに答えるために作られています。*よりよく学べているのか、それとも単に多く復習しているだけなのか？* いくつかの目安です。

- **復習が増え、成熟カードの定着率が下がっている。** 定着させるより速く追加しています。新しいカードのペースを落としましょう。たまった分が減っていきます。
- **成熟カードの定着率も復習の量も安定している。** これが目標です。スケジュールが機能しています。そのまま続けましょう。
- **全体の定着率は高いが、成熟シグナルがまだない。** 何も問題ありません。カードがまだ 30 日の間隔に達していないだけです。1 か月待ちましょう。
- **1 つのデッキだけがほかよりずっと低い。** そのデッキにはカードの問題か前提知識の問題があり、意志の力の問題ではありません。[デッキの比較](#deck-comparison)を参照してください。
- **連続記録は長いが、マスの色が薄い。** 1 日 1 枚でも連続記録は続きますが、スケジュールは追いつきません。[現在の期限]{.ui} にも注目しましょう。

::: gotcha
#### 正直に評価しないと、数値はうそをつきます

この章の数値はすべて、あなたの評価から作られています。半分しか思い出せなかったカードに「普通」を押すと、習熟度、定着率、間隔がまとめて水増しされ、カードは本来より遅く戻ってきます。「難しい」は失敗ではなく、情報です。
:::

## 「AIに聞く」：自分専用のチューターに伝える {#ask-ai}

数週間たつと、JustFlip! はどのチャット AI も知らないことを知っています。あなたのカードのうち、どれを習得し、どれを何度も間違えているかです。**AIに聞く**は、それをすぐに使えるプロンプト（指示付きの学習レポート）に変えます。ChatGPT、Claude、Gemini などのアシスタントに貼り付けて使います。

### 場所

| 開く場所 | 選ぶ項目 | 範囲 |
|---|---|---|
| カード一覧のカード（長押しまたは右クリック） | [AIに聞く]{.ui} | そのカード |
| 復習画面上部のキラキラボタン | [カードについてAIに聞く]{.ui} | 表示中のカード |
| 復習画面上部のキラキラボタン | [デッキについてAIに聞く]{.ui} **（Pro）** | そのカードのデッキ全体 |
| デッキ一覧のデッキ（長押しまたは右クリック） | [AIに聞く]{.ui} **（Pro）** | デッキ全体 |
| 復習後の結果画面 | [AIに聞く]{.ui} | そのセッションのカード |

1 枚のカードとセッションのレポートは無料です。デッキのレポートは **Pro** です。Pro がない場合、これらのメニュー項目には鍵が付き、Pro の画面が開きます。

![「AIに聞く」シート：「プロンプトをコピー」と「プロンプトを保存」、「AIチャットで開く」のリンク、そしてプロンプトのプレビュー。](images/manual/{lang}/09-ask-ai-sheet.jpg){.phone}

### レポートの内容

**デッキのレポート**は、カードを履歴によって分類します。

- **苦手なカード**：失念が 1 回以上ある、易しさが低い、またはまだ学習中のカード。苦手な順に並び、それぞれに答えと 1 行の統計が付きます。たとえば "failed 4 of 6 review(s) · 2 lapse(s) · ease 1.8 · avg 21s to answer"。レポートには最大 25 枚まで含まれます。
- **習得したカード**：前提として問題だけが並びます。AI がそれをもう一度教えて時間を無駄にしないためです（最大 60 枚）。
- まだ履歴のない**新しいデッキ**は、カードが 1 枚ずつ並べられ、AI にはテーマを推測して基礎を教えるよう依頼されます。

**カードのレポート**は 1 枚のカードを扱います。問題と答え、そしてそのカードでのあなたの履歴です。**セッションのレポート**は、終えたばかりの復習のカードを、それぞれに付けた評価とともに並べます。

### AI に依頼する内容

指示は、どの範囲でも同じ考え方です。

1. **前提知識を教える。** 間違いはしばしば、デッキが扱っていない背景知識を指し示しています。そこで AI に、基礎から教えるよう依頼します。
2. 間違った答えから推測される**誤解を説明する**。
3. **情報源を勧める。** それぞれ直接リンク付きで、公式のドキュメントや信頼できる資料を優先します。
4. **必要に応じて新しいフラッシュカードを書く。** 足りない部分を補うカードを、そのまま読み込める CSV（`question,answer`）としてコードブロックに書きます。

プロンプト自体は、チャットモデルが最も確実に従える英語で書かれていますが、AI には**デバイスの言語で返答する**よう、また新しいフラッシュカードはデッキの言語で書くよう依頼しています。

### 送る

シートには [プロンプトをコピー]{.ui} と、`.txt` ファイルとして保存する [プロンプトを保存]{.ui} があります。[AIチャットで開く]{.ui} の下にある ChatGPT、Claude、Gemini の行は、アプリがインストールされていればアプリで、なければブラウザで、新しい会話を開きます。プロンプトは引き継がれないので、先にコピーしてから開き、貼り付けてください。下部の [プロンプトのプレビュー]{.ui} には、共有しようとしている内容がそのまま表示されます。

::: tip
#### ループを閉じる

AI が新しいカードを書いてくれたら、その返答をコピーし、「コレクション」の一覧に戻って [追加または読み込み]{.ui} › [カードを貼り付け]{.ui} を選びます。JustFlip! は返答の中から（コードブロックの中でも）CSV を見つけ出し、プレビューを表示します。何かが保存される前に、デッキを選べます。
:::

::: note
#### JustFlip! が AI と通信することはありません

「AIに聞く」の中に AI はありません。JustFlip! はデバイス上でテキストを組み立てるだけで、AI サービスに接続することはありません。レポートがアプリの外に出るのは、**あなたが**コピーまたは保存したときだけです。その先は、あなたと貼り付け先のサービスとの間のことなので、カードに個人的な内容が含まれている場合は、先にプレビューを確認してください。
:::

::: gotcha
#### 画像だけのカードはプレースホルダーとして届きます

レポートはプレーンテキストです。片方の面にテキストがなく、画像やオーディオだけのカードは、AI には "(no text — this card uses an image, audio, or PDF)" として届きます。進捗トラッカーはデッキのレポートから完全に除外されます。デッキがほとんど画像なら、重要なカードに 1 行テキストを加えておきましょう。
:::

## 統計を書き出す {#export}

自分のスプレッドシートやグラフに使うために、コレクションの統計をすべて書き出せます。書き出しは無料です。

- **iPhone と iPad**：「コレクション」の一覧でコレクションを長押しし、[統計を書き出す]{.ui} を選んでから、[スプレッドシート（CSV）]{.ui} または [完全データ（JSON）]{.ui} を選びます。ファイルの保存先を選びます。
- **Mac**：コレクションを右クリックすると同じメニューが表示されます。または、コレクションを選択して **ファイル › Export Statistics…** を選ぶと、CSV が保存されます。

ファイル名はコレクションの名前に基づきます。たとえば `Spanish.flashcards-stats.csv` です。

### CSV：カードごとに 1 行

| 列 | 内容 |
|---|---|
| `interest`、`deck` | カードの場所 |
| `question`、`answer` | カードのテキスト |
| `state` | `unseen`、`learning`、`reviewing`、`relearning`、`graduated` のいずれか |
| `ease_factor` | カードの易しさ（新しいカードは 2.5） |
| `interval_days` | 現在の間隔（日数） |
| `due_date` | 次の復習。ISO 8601 形式の日時 |
| `lapses` | 覚えたあとに忘れた回数 |
| `streak` | 連続正解の回数 |
| `total_reviews` | 記録されたすべての復習の回数 |
| `success_rate` | 「普通」か「簡単」の回答の割合（0〜1） |
| `avg_review_time_sec` | 回答までの平均時間 |
| `last_reviewed` | 最後の復習の日時。一度もなければ空欄 |

### JSON：すべて

JSON の書き出しには、カードごとの同じフィールドに加えて、デッキごとの段階の概要、開始・終了・カード枚数・正答率を含むすべての学習セッション、そして各カードの完全な**履歴**が含まれます。履歴には、すべての復習について、日時、評価、回答時間、前後の間隔と易しさが記録されています。自分の忘却曲線をグラフにしたいときに使ってください。

::: gotcha
#### 統計の書き出しは一方通行です

統計ファイルは閲覧用で、復元用ではありません。JustFlip! に読み込み直すことはできず、画像や音声も含まれません。進捗*ごと*コレクションを移動したりバックアップしたりするには、代わりに [アーカイブを書き出す]{.ui} を使ってください。第 10 章を参照してください。
:::
