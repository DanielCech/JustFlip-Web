## トラブルシューティング {#troubleshooting}

### カードと復習

| 見えている現象 | 対処 | 章 |
|---|---|---|
| カードがまったく読み上げられない | その面の [言語]{.ui} を設定します。「なし」の面は読み上げられません | 3、7 |
| 言語は設定済みなのに再生ボタンがない | iOS の **設定 › アクセシビリティ › リーダーと読み上げ › 声** で声をダウンロードします | 7 |
| カードに `{…}` の波かっこが表示される | 読み上げのヒントが効くのは、角かっこ、数式、画像のあとだけです。テキストを `[…]` で囲みます | 3 |
| めくったあと「普通」と「簡単」がない | **設定 › 動作 › 厳しい評価** がオンです。オフにするか、めくる前に評価します | 2 |
| 新しいデッキの [復習予定カード]{.ui} に何もない | 一度も学習していないカードはまだ期限ではありません。「今日」、[新しいカード]{.ui}、または [すべてのカード]{.ui} を使います | 2 |
| 「もう一度」のカードが同じセッションで戻ってこない | 仕様です。5 分後に期限を迎え、次のセッションで出てきます | 6 |
| 優先度のスライダーを動かしても期限のカード数が変わらない | 仕様です。優先度が変えるのは、上限のあるセッションの順序だけです | 6 |
| 後回しにしたデッキが表示されないまま | 「デッキ」画面 › [デッキのオプション]{.ui} › [復習の優先度]{.ui} › 再開 | 6 |
| 後回しにした 1 枚のカードを再開できない | 日付が来ると終わります。または [すべてのカード]{.ui} から「明日」まで後回しにし直します | 6 |
| 1〜4 キーや Space キーが効かない | 答えを入力中、「厳しい評価」がオン、またはオクルージョンの答えがまだ表示されていません | 8 |
| 長いカードがいつもシートで開く | 大きな文字サイズでは、カードは縮小して収められません。分割するか、JustFlip! の文字サイズを小さくします | 11 |
| リマインダーが届かない | **設定 › リマインダー › 毎日の復習リマインダー** をオンにし、iOS の設定で通知を許可します | 2 |
| ガイドが表示されなくなった | **設定 › ヘルプ › ガイド** でもう一度表示されます | 1 |

### 画像、音声、編集

| 見えている現象 | 対処 | 章 |
|---|---|---|
| ダークモードで画像が消える | 白か明るい色の背景を付けます | 4 |
| 読み込み後に画像が見当たらない | Anki の読み込みレポートを確認します。SVG には対応していません | 4、5 |
| 画像や音声を置き換えたら、面のテキストが消えた | 「画像」または「オーディオ」タブで保存されました。保存する前に「テキスト」に戻ります | 4 |
| 「カードを読み上げ」がカードをスキップする | 両方の面に、テキストと、声がインストールされた言語が必要です | 7 |
| 再生が勝手に止まった | 電話やほかのアプリが音声を使いました。[ここから読み上げ]{.ui} で再開します | 7 |

### 読み込み

| 見えている現象 | 対処 | 章 |
|---|---|---|
| 行数やノート数よりカードが少ない | 問題が同じカードが統合された（デッキファイル）、または問題のない行がスキップされた（CSV） | 5 |
| Anki のノート数よりカードが多い | 穴埋めの番号ごとに 1 枚のカードになります。想定どおりです | 5 |
| デッキが 2 つできた | CSV は常に新しいデッキを作ります。[新しいコピーを追加]{.ui} での Anki の読み込みも同じです | 5 |
| 読み込み直したら画像だけのカードが 2 倍になった | 照合に使う問題がありません。余分なものを削除します | 5 |
| 最初のカードが「問題 / 答え」になっている | [最初の行をヘッダとしてスキップ]{.ui} をオンにします | 5 |
| すべてのテキストが 1 つの列に入っている | CSV のプレビューで [区切り文字]{.ui} を変更します | 5 |
| 読み込みのあと、編集が消えた | ファイルの内容で置き換えられました。ファイルにも同じ修正をします | 5 |
| スケジュールが巻き戻った、または削除したカードが戻ってきた | 古いコレクションのアーカイブが読み込まれました | 5、10 |
| 読み込んだカードが違うデッキに入った | 2 つのデッキが同じ名前です。どちらかの名前を変えます | 1 |
| 新しいコレクションが表示されない | 同じ名前のコレクションがすでにあり、そちらが使われました | 1 |

### 同期、デバイス、データ

| 見えている現象 | 対処 | 章 |
|---|---|---|
| 同期の状況が [利用できません]{.ui} | iCloud にサインインし、JustFlip! が iCloud を使えるようにします | 10 |
| 変更がもう一方のデバイスに届かない | 両方のデバイスの「iCloud同期」画面で、アップロードとダウンロードの日時を比べます | 10 |
| バックアップの保存先が [ローカルのみ]{.ui} | 書き出したアーカイブも、どこか安全な場所に保管しておきます | 10 |
| 同じ名前のコレクションが 2 つできた | 次の同期のあと、JustFlip! が自動的に統合します | 10 |
| ウィジェットの枚数が古い | そのデバイスで JustFlip! を開きます。ウィジェットは、アプリがそこに最後に保存した内容を表示します | 8 |
| Watch に [iPhoneでJustFlipを開くと、カードが同期されます。]{.ui} と表示される | iPhone のアプリを一度開きます | 8 |
| Watch に「N件をiPhoneに同期中」と表示される | iPhone を近くに置きます。評価は届けられ、一度だけ反映されます | 8 |
| カードが Spotlight に表示されない | コレクション*と*デッキの両方で [デバイスの検索に含める]{.ui} を確認します。単語の先頭で検索します | 8 |
| JustFlip! がダークモードに従わない | テーマがライトかダークに固定されています。[システム]{.ui} を選びます | 11 |
| 「新機能」のシートが空 | オフラインです。[再試行]{.ui} または [ブラウザで開く]{.ui} を使います | 8 |
| 統計のメニュー項目に鍵が付いている | 統計は Pro（トライアルを含む）の機能です | 9 |
| 復元で購入が見つからない | Pro を購入したときの Apple アカウントを使います | 1 |

## 用語集 {#glossary}

| 用語 | 意味 |
|---|---|
| **コレクション** | ライブラリの最上位の階層。デッキを収める分野 |
| **デッキ** | コレクションの中の、テーマを絞ったカードのまとまり |
| **カード** | 問題と答え。各面にテキスト、画像、音声、言語があります |
| **今日** | 「コレクション」画面のパネル。すべてのコレクションの期限のカードと、1 日の上限までの新しいカードを集めます |
| **期限** | 復習の時期が来たカードで、卒業済みでも後回しでもないもの |
| **新しいカード** | 一度も学習していないカード |
| **苦手** | 期限にかかわらず、前回の評価が「もう一度」か「難しい」だったカード |
| **確認済み** | 閲覧中に初めてカードをめくったときに JustFlip! が付ける記録。評価ではありません |
| **間隔** | カードが戻ってくるまでの時間。数分から数か月まで |
| **易しさ** | カードごとの間隔の成長率。2.5 から始まり、1.3〜3.5 の範囲に保たれます |
| **段階** | 未学習、学習中、復習中（間隔 7 日以上）、卒業（30 日以上）、再学習中 |
| **習熟度** | 前回の評価が「普通」か「簡単」だったデッキのカードの割合。進捗トラッカーは自身の進捗を加えます |
| **定着率** | 「普通」か「簡単」と評価された復習の割合 |
| **成熟した復習** | 間隔がすでに 30 日に達していたカードの復習 |
| **失念** | 一度覚えたカードを忘れること |
| **リーチ** | 8 回以上忘れたカード。[何度も忘れているカード]{.ui} に表示されます |
| **連続記録** | 1 回以上復習した日が続いた日数。2 日までの抜けはつなぎ合わされます |
| **予測** | これからの各日に期限を迎えるカードの枚数。期限切れのカードは今日に加えられます |
| **緊急度** | 期限のカード、その遅れ具合、最後に学習してからの時間、習熟度を組み合わせたスコア |
| **卒業させる** | 履歴を残したまま、カードを復習から外すこと。「カードを復習に戻す」で元に戻せます |
| **後回し** | 評価せずに、カード、デッキ、コレクションを選んだ日まで脇に置くこと |
| **復習の優先度** | 上限のあるセッションでどのカードを先に出すかを決める 0〜100 % の重み（初期設定は 75 %） |
| **厳しい評価** | カードをめくったあとは「もう一度」と「難しい」だけを残す設定 |
| **スマートスケジュール** | 約 90 % の想起率を目指す FSRS-5 スケジューラ（Pro、ベータ） |
| **進捗トラッカー** | フラッシュカードではテストできないスキルのために、0〜100 で自己評価するカード（Pro） |
| **穴埋め（クローズ）** | `{{c1::…}}` で書く穴埋めカード |
| **読み上げのヒント** | カードの一部のあとに付ける `{…}`。代わりに読み上げる内容を声に伝えます |
| **添付の目印** | テキストの中に画像を配置する `![attachment:0]` |
| **画像の説明** | 画像の代わりに VoiceOver が読み上げるテキスト |
| **画像オクルージョン** | 覆った領域を持つ画像。領域ごとに 1 枚のカードになります |
| **カードを読み上げ** | デッキ全体をハンズフリーで聞く機能。問題、4 秒の間、答え、チャイム（Pro） |
| **自動の声** | その言語でインストールされている最良の声。プレミアム、拡張、標準の順 |
| **AIに聞く** | 自分のチャット AI に貼り付けるために JustFlip! が作る、学習レポートのプロンプト |
| **ガイド** | コントロールを説明する 1 回限りの案内。**設定 › ヘルプ › ガイド** でもう一度表示できます |
| **スターターライブラリ** | 初回起動時と **設定 › ヘルプ › ライブラリ** で提供される、すぐに使えるデッキ |
| **コレクションのアーカイブ** | 1 つのコレクションを進捗ごと書き出した `.flashcards.zip` |
| **フルバックアップ** | ライブラリ全体の週ごとの `.justflip` アーカイブ。最新の 10 個が保持されます |
| **進捗スナップショット** | メディアを含まない、進捗の毎日のバックアップ。最新の 30 個が保持されます |
| **デバイスの検索に含める** | カードを Spotlight に表示するかどうかを決める、コレクションとデッキのスイッチ |

## 無料版と Pro {#free-pro}

JustFlip! は無料で使え、カードの枚数に制限はありません。Pro は、ライブラリの 2 つの上限を取り払い、いくつかの強力な機能を追加します。無料トライアルが提供されている場合は、その期間中 Pro の機能が使えます。

| 機能 | 無料 | Pro | 章 |
|---|---|---|---|
| コレクション | 3 | 無制限 | 1 |
| コレクションごとのデッキ | 5 | 無制限 | 1 |
| カード、書式、画像、音声、画像オクルージョン | ✓ | ✓ | 3、4 |
| 読み込みと書き出し（Anki、CSV、デッキファイル、アーカイブ） | ✓ | ✓ | 5 |
| 復習、優先度、後回し、卒業 | ✓ | ✓ | 2、6 |
| 再生ボタンと声の選択 | ✓ | ✓ | 7 |
| Apple Watch、ウィジェット、Siri、Spotlight | ✓ | ✓ | 8 |
| iCloud 同期、バックアップ、復元 | ✓ | ✓ | 10 |
| テーマと文字サイズ | ✓ | ✓ | 11 |
| カードやセッションについて AI に聞く | ✓ | ✓ | 9 |
| デッキ全体について AI に聞く | — | ✓ | 9 |
| カードを読み上げとバックグラウンド再生 | — | ✓ | 7 |
| 統計 | — | ✓ | 9 |
| 進捗トラッカー | — | ✓ | 6 |
| スマートスケジュール（ベータ） | — | ✓ | 6 |

プラン、購入、復元については第 1 章を参照してください。

## ファイル形式 {#formats}

| ファイル | 内容 | 作成元 | 読み込み時の動作 |
|---|---|---|---|
| `.flashcards` | テキストだけのデッキ | AI、デッキのページ、あなた | 一致するデッキを（問題のテキストで）更新 |
| `.flashcards.zip` | 画像と音声を含むデッキ、またはコレクションのアーカイブ | コーディングエージェント用スキル、デッキのページ、[アーカイブを書き出す]{.ui} | デッキファイルは問題で更新。アーカイブは進捗を含めてコレクションを復元 |
| `.apkg`、`.colpkg` | Anki のデッキまたはコレクション | Anki | 新しいデッキ、または既存のものをスキップ / 更新 |
| `.csv` | 1 行に 1 枚のカード | 任意のスプレッドシート | 常に新しいデッキ |
| `.flashcards-stats.csv` / `.json` | 閲覧用の統計 | [統計を書き出す]{.ui} | 読み込めません |
| `.justflip` | ライブラリ全体のフルバックアップ | 自動バックアップ、[バックアップを書き出す]{.ui} | **設定 › データの安全性 › バックアップを復元** |

AI ツールやデッキの作成者向けに書かれたデッキファイルのコンテンツ形式は、[AI プロンプト](https://just-flip.app/ai-prompt.html)と一緒に公開しています。

## キーボードショートカット {#shortcuts}

Mac と、ハードウェアキーボードを接続した iPad で使えます。

| キー | 操作 |
|---|---|
| Space | カードをめくる、またはオクルージョンの領域を表示する |
| 1 · 2 · 3 · 4 | もう一度 · 難しい · 普通 · 簡単 |
| Return | 入力した答えを確認する |
| ⇧⌘I | Import Cards…（Mac） |
| ⇧⌘E | Export Interest…（Mac） |

キーが効かないことがある理由など、詳しくは第 8 章で説明しています。

## マークアップ早見表 {#markup}

| 書き方 | 結果 |
|---|---|
| `**bold**` · `*italic*` · `` `code` `` | **太字** · *斜体* · `code` |
| `{{c1::answer::hint}}` | ヒントを付けられる空欄 |
| `::: hero` … `:::` | とても大きく、中央に配置された内容 |
| `$x^2$` · `$$` … `$$` | インライン数式 · 数式ブロック |
| ```` ```swift ```` · ```` ```mermaid ```` | 色分けされたコード · ダイアグラム |
| `| A | B |` + `|---|---|` | 表（最大 2 × 5） |
| `![attachment:0]` | その面の画像を、この位置に |
| `[shown]{spoken}` | 別の内容を読み上げる |

すべてのルールを載せた完全な早見表は、第 3 章の最後にあります。
