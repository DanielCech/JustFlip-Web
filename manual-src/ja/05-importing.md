# デッキを取り込む {#importing number="5"}

::: lede
カードをすべて自分で入力する必要はありません。JustFlip! は Anki パッケージ、スプレッドシート、AI が書いたデッキファイルを読み込めます。また、コレクションを 1 つのアーカイブとして書き出すこともできます。この章では、ファイルの種類ごとの読み込み方、何が引き継がれるか、そして読み込みでカードが追加されるのか既存のカードが更新されるのかを決める、いくつかのルールを説明します。
:::

::: inthischapter
- iPhone、iPad、Mac で読み込みの場所を見つける
- Anki のデッキを移し、読み込みレポートを読む
- スプレッドシートをデッキにする
- AI が作ったデッキや厳選ライブラリのデッキを読み込む
- 読み込み直す前に、何が起きるかを知っておく
- コレクションを書き出して保管・共有する
:::

この章のすべての機能と同じく、読み込みは無料版で使えます。

## 読み込みの場所 {#where}

読み込みはすべて**コレクション**画面から始まります。JustFlip! はファイルを名前と内容から判別するので、同じ入り口からどの形式でも読み込めます。

| デバイス | 方法 |
|---|---|
| iPhone、iPad | [追加または読み込み]{.ui} メニュー（トレイのボタン）→ [カードを読み込む]{.ui} |
| iPhone、iPad | 「ファイル」、「メール」、Safari で：ファイルを共有するか、JustFlip! で開く |
| iPad、Mac | ファイルをコレクションの一覧にドラッグ（[ドロップして読み込む]{.ui} と表示されます） |
| Mac | **ファイル › Import Cards…**（⇧⌘I）または **ファイル › Import Interest Archive…** |
| すべて | コレクションを長押し → [カードを読み込む]{.ui}：CSV や Anki のファイルをそのコレクションに直接読み込む |
| すべて | [追加または読み込み]{.ui} → [カードを貼り付け]{.ui}：コピーしたカード（[カードを貼り付け](#paste)を参照） |

メインの読み込みでは、複数のファイルやフォルダごとまとめて読み込めます。フォルダ内の対応ファイルはすべて読み込まれます。

![「コレクション」画面の「追加または読み込み」メニュー。「カードを読み込む」と「カードを貼り付け」があります。](images/manual/{lang}/05-import-menu.jpg){.phone}

### ファイルごとの読み込み結果

| ファイル | 内容 | 読み込み先 |
|---|---|---|
| `.apkg`、`.colpkg` | Anki のデッキまたはコレクション | 選んだコレクション。Anki のデッキごとに 1 つのデッキ |
| `.csv` | スプレッドシート。1 行に 1 枚のカード | 選んだコレクション。常に新しいデッキ |
| `.flashcards` | テキストだけのデッキファイル。AI が作ったものや厳選デッキ | ファイル内で指定されたコレクション |
| `.flashcards.zip` | 画像や音声を含むデッキファイル、または書き出したコレクション | ファイル内で指定されたコレクション |

Anki と CSV のファイルでは、JustFlip! はまずカードをどこに入れるかを尋ねます。[カードを読み込む]{.ui} シートには [コレクション]{.ui} メニュー（[新規コレクション…]{.ui} を含む）があり、スプレッドシートの場合は [デッキ名]{.ui} もあります。[続ける]{.ui} をタップします。

読み込みで新しいコレクションが作られる場合、シートには [デバイスの検索に含める]{.ui} も表示されます。そのカードを Spotlight に表示できるかどうかを決めます（第 8 章）。

## Anki のデッキ {#anki}

JustFlip! は、Anki のデッキパッケージ（`.apkg`）とコレクションパッケージ（`.colpkg`）を、古いバージョンと現行バージョンの両方から読み込めます。Anki で **ファイル › エクスポート** を選び、*Anki デッキパッケージ* を選んで、メディアを含めます。そのファイルを上記の方法で読み込みます。

約束はシンプルです。**学習内容は引き継がれ、Anki の見た目は引き継がれません。** 言葉、画像、音声、数式、タグは届きます。Anki のスタイル、スクリプト、スケジュールは残ります。

### 引き継がれるもの

- **すべてのカード。** Anki のカードはそれぞれ JustFlip! のカードになります。表/裏、逆向き、任意の逆向きのノートタイプはすべて使えます。
- **穴埋めノートは分割されます。** `{{c1::…}}`、`{{c2::…}}`、`{{c3::…}}` を含むノートは、Anki と同じく番号ごとに 1 枚、計 3 枚の JustFlip! カードになります。各カードは自分の番号を空欄にし、ほかの番号は埋めた状態で表示します。`{{c1::Paris::capital}}` のようなヒントも保持されます。
- **画像**は、登場順にインラインで。Anki の画像の代替テキストは、声がその画像について読み上げる内容になります。
- **音声。** 面にあるすべての `[sound:…]` が順番どおりに保持されます（第 4 章）。
- **画像オクルージョン**は、Anki 標準のツールのものも、以前からある Image Occlusion Enhanced アドオンのものも、どちらもネイティブのオクルージョンカードになります。
- **書式**：太字、斜体、リスト、リンク、小さな表、数式、下付き・上付き文字。
- **タグ。**
- **デッキの階層は平らになります。** JustFlip! にはサブデッキがないので、`Languages::Spanish::Verbs` は **Languages / Spanish / Verbs** という 1 つのデッキになります。

### Anki に残るもの

- **復習の履歴。** すべてのカードは新規から始まります。Anki の間隔、易しさ、FSRS の設定は読み込まれません。
- **スタイル。** 独自の CSS、フォント、色は簡略化されます。
- **コード。** JavaScript やアドオンは実行されず、保持もされません。
- **オンラインのもの。** リモートの画像、埋め込みページ、iframe は取得されません。
- **ビデオ。**
- **フラグ。** Anki のカードのフラグは引き継がれません。
- **繰り返される問題。** Anki は解答面に問題をもう一度表示しますが、JustFlip! はその場でカードをめくるので、その写しは取り除かれます。例外は穴埋めカードで、繰り返される文*そのもの*が答えだからです。

::: gotcha
#### Anki の穴埋めノートは複数のカードです

Anki で 300 ノートと表示されるデッキが、700 枚のカードとして届くことがあります。重複ではありません。Anki でも JustFlip! でも、穴埋めの番号ごとに 1 枚のカードになります。読み込みシートの数はカードの枚数です。
:::

::: gotcha
#### 読み込んだカードには言語がありません

Anki はフィールドの言語を保存しないため、読み込んだカードはすべて [言語]{.ui} が**なし**の状態から始まります。言語のない面は読み上げられません（第 3 章）。読み込んだデッキを聞きたい場合は、カードに言語を設定してください。
:::

### 読み込みシート {#anki-report}

[追加または読み込み]{.ui} メニュー、「ファイル」、またはドラッグで Anki のファイルを 1 つ読み込むと、[Anki から読み込む]{.ui} が開きます。まずパッケージを読み取り（[パッケージを確認しています…]{.ui}、[展開しています…]{.ui}、[カードを読み込んでいます…]{.ui}）、続いて [学習の準備ができました]{.ui} と表示されます。見つかった Anki のデッキ、[カード]{.ui}、[画像]{.ui}、[オーディオ]{.ui} の数が示されます。

![「Anki から読み込む」シート：概要、「変更点」、「オプション」。](images/manual/{lang}/05-anki-report.jpg){.phone}

[変更点]{.ui} の下には読み込みレポートがあります。確定する前に知っておくべきことが、項目ごとに 1 文ずつ簡潔に書かれています。たとえば、

- *カードはここで最初から始まります。Anki の復習履歴は Anki に残ります。*
- *解答は質問を繰り返しません。JustFlip はめくる間も質問を表示します。*
- *画像 12 件を読み込めなかったため除きました。*
- *問題面が空のカード 3 枚をスキップしました。*
- *Anki のアドオン由来のフィールド 2 件を除きました。*

カードの*中*には何も書き込まれません。見つからない画像は単に欠けているだけで、それを伝えるのはこのレポートだけです。

[オプション]{.ui} の下には、読み込みで作られる [デッキ]{.ui} と、1 つの選択肢 [同じカードをすでに持っている場合]{.ui} があります。

| オプション | このパッケージからすでに読み込んだカード |
|---|---|
| [新しいコピーを追加]{.ui} | そのまま残り、パッケージ全体が新しいデッキとしてもう一度追加されます。初期設定 |
| [すでにあるものをスキップ]{.ui} | そのまま残り、新しいカードだけが追加されます |
| [更新して学習状況を保つ]{.ui} | テキスト、画像、タグがファイルの内容で更新され、スケジュールはそのままです |

JustFlip! は、読み込んだ各カードが Anki のどのノートとカードから来たかを記憶しているので、JustFlip! で問題を編集したあとでも照合できます。[読み込む]{.ui} をタップするとカードが追加されます。

::: tip
#### Anki でも学習を続けているデッキを更新する

Anki で作業を続け、もう一度書き出して、[更新して学習状況を保つ]{.ui} で読み込みます。修正が反映され、新しいノートが追加され、JustFlip! のスケジュールはそのまま残ります。
:::

::: gotcha
#### クイック読み込みでは選択肢が出ません

Anki のファイルをすぐに読み込む経路が 2 つあり、どちらもシートを表示せず、常に新しいコピーとして読み込みます。コレクション自身のメニューの [カードを読み込む]{.ui} と、複数の Anki ファイルを一度に選んだ場合です。すでにあるカードをスキップしたり更新したりするには、[追加または読み込み]{.ui} メニューから 1 ファイルずつ読み込んでください。
:::

## スプレッドシート（CSV） {#csv}

CSV ファイルは、単語リスト、用語集、ほかのアプリからの書き出しなど、一覧を JustFlip! に移すいちばん簡単な方法です。1 行が 1 枚のカードで、ある列が問題、別の列が答えになります。

```csv
問題,答え
el perro,犬
el gato,猫
"la casa, el hogar",家
```

[続ける]{.ui} のあと、[CSVを読み込む]{.ui} にライブプレビューが表示されます。

- **[区切り文字]{.ui}**：カンマ、セミコロン、パイプ、タブ。JustFlip! は最初の数行から推測します。列がおかしく見える場合は変更してください。
- **[最初の行をヘッダとしてスキップ]{.ui}**：最初はオフです。1 行目が列の見出しなら、オンにします。
- **[列のマッピング]{.ui}**：どの列を [表面（問題）]{.ui}、どの列を [裏面（解答）]{.ui} にするかを選びます。ほかの列は無視されます。
- **[プレビュー]{.ui}**：最初の数行が、読み込まれるとおりに表示されます。

問題なければ **読み込む（N）** をタップします。

![「CSVを読み込む」のプレビュー。区切り文字、ヘッダのスイッチ、列のマッピング、行のプレビュー。](images/manual/{lang}/05-csv-preview.jpg){.phone}

やり直しを防ぐための、いくつかの細かな点です。

- 区切り文字や改行を含むフィールドは、ダブルクォートで囲みます。その中のダブルクォートは `""` と書きます。
- テキストには第 3 章のカードのマークアップ（太字、数式、穴埋め）が使えます。CSV のセルにある `{{c1::…}}` は、すべての空欄を含む**1 枚**のカードのままです。CSV のカードは、Anki の穴埋めノートのように分割されることはありません。
- 問題が空の行はスキップされます。答えが空の行は、答えのないカードとして読み込まれます。
- CSV のカードには、言語、画像、タグはありません。

::: gotcha
#### ヘッダ行がカードになってしまう

[最初の行をヘッダとしてスキップ]{.ui} は最初オフです。オンにし忘れると、列の見出しが「問題」という問題と「答え」という答えのカードになってしまいます。読み込む前に、プレビューの 1 行目を確認してください。
:::

::: gotcha
#### CSV は何も更新しません

CSV の読み込みは、同じ名前のデッキがすでにあっても、毎回**新しい**デッキを作ります。結果として同名のデッキが 2 つになります。スプレッドシートから読み込んだカードを変更するには、JustFlip! で編集するか、修正したファイルを読み込む前に古いデッキを削除してください。
:::

## AI で作ったデッキ {#ai}

いちばん学びやすいデッキは、*あなた自身*の素材から作ったものです。ノート、本の 1 章、講義の書き起こしなど。JustFlip! 自身は AI と通信しません。代わりに、Web サイトが JustFlip! のデッキファイルの書き方をあなたの AI に伝え、あなたはその結果を読み込みます。

| ページ | 対象 | 得られるもの |
|---|---|---|
| [AI プロンプト](https://just-flip.app/ai-prompt.html) | ChatGPT、Claude、Gemini などのチャット AI | テキストだけの `.flashcards` ファイル |
| [AI スキル](https://just-flip.app/ai-skill.html) | コンピュータ上のファイルを読めるコーディングエージェント | 画像と音声を含む `.flashcards.zip` |

チャット AI はテキストしか返せないので、AI プロンプトのページではテキストだけのデッキを依頼します。コーディングエージェントなら、ローカルの画像や音声を開いて zip にまとめられ、説明、ライセンス、さらには画像オクルージョンまで含められます。

ファイルはほかと同じように読み込みます。ファイル自体がコレクションとデッキの名前を指定しているので、設定シートは表示されません。JustFlip! はその名前のコレクションがあればそれを使い、なければ作成します。デッキファイルでは各デッキの言語も指定できるので、カードはすぐに読み上げられる状態になります。

::: tip
#### 学ぶ前に見直す

AI は自信満々に間違えることがあります。新しいデッキは最初の復習の前に一度ざっと目を通し、疑わしいものは修正するか削除しましょう。10 分の編集は、間違った答えを何週間も復習するよりずっとましです。
:::

## カードを貼り付け {#paste}

カードがすでにクリップボードにあることもあります。チャット AI の返答、スプレッドシートの列、「メモ」の一覧など。[追加または読み込み]{.ui} → [カードを貼り付け]{.ui} を選びます。[使い方]{.ui} の説明にあるとおり、カードを 1 行に 1 枚、問題と答えをカンマで区切ってコピーし、「ペースト」をタップします。JustFlip! はコピーした内容の中から、チャット AI のコードブロックの中も含めてカードを見つけ出し、周りのテキストは無視します。

貼り付けた一覧は、CSV ファイルと同じ [カードを読み込む]{.ui} と [CSVを読み込む]{.ui} のシートを通り、名前を変えなければ **貼り付けたカード** というデッキに入ります。貼り付けたデッキファイル（AI プロンプトのページで AI が書く JSON）は、`.flashcards` ファイルと同じように読み込まれます。デバイスの外に出るものは何もありません。

## 厳選デッキ {#curated}

Web サイトの[デッキのページ](https://just-flip.app/decks/)は、すぐに使えるデッキの小さなライブラリです。語学、音楽、数学、プログラミング、科学のデッキを、アプリが対応するすべての言語で用意しています。**デッキをダウンロード** をタップし、ファイルを JustFlip! で開きます。中身は普通の `.flashcards` と `.flashcards.zip` ファイルなので、[同じファイルをもう一度読み込む](#reimport)の内容がそのまま当てはまります。

## 同じファイルをもう一度読み込む {#reimport}

デッキファイル（AI、厳選ライブラリ、または自分のエディタで作った `.flashcards` と `.flashcards.zip`）は、何度でも読み込み直せるように設計されています。ファイルの誤字を直し、カードを 10 枚追加して読み込めば、デッキは 2 倍になるのではなく更新されます。

JustFlip! は次のように照合します。

1. **コレクション**は、ファイル内のコレクション名と一致するものです。大文字と小文字や余分な空白は区別されません。
2. **デッキ**は、そのコレクションの中で、ファイル内のデッキ名と*完全に*一致するものです。
3. **各カード**は、書かれたとおりの**問題のテキスト**で照合されます。一致したカードはその場で更新され、答え、画像、音声がファイルの内容に置き換わり、進捗は保たれます。一致しないカードは追加されます。

デッキにあってファイルにないカードはそのまま残ります。読み込みで何かが削除されることはありません。

::: gotcha
#### 2 枚のカード、1 つの問題

カードは問題で照合されるため、1 つのデッキで問題のテキストが同じ 2 枚のカード（「この音名は？」「訳しなさい：」など）は、まったく新しく読み込んだ場合でも 1 枚になってしまいます。カードごとに別々の問題にするか、共通の問いかけをデッキ名に移しましょう。
:::

::: gotcha
#### 画像だけのカードは毎回追加されます

問題のテキストがまったくなく画像だけのカードは照合できないため、統合されることはありません。そのおかげで「これは何？」という画像のデッキは崩れませんが、ファイルを読み込み直すと、そうしたカードがもう一度追加されてしまいます。デッキファイルでは、こうしたカードの `q` フィールドそのものを省いてください。空の `"q": ""` は問題のテキストとして扱われ、ほかの空の問題とすべて統合されてしまいます。
:::

::: gotcha
#### 自分の編集は読み込み直しで失われます

カードを更新すると、その内容はファイルの内容に置き換わります。JustFlip! で答えを修正した場合は、ファイルにも同じ修正をしてください。そうしないと、次の読み込みで古い答えに戻ってしまいます。また、JustFlip! でデッキの名前を変えると、ファイルはそのデッキを見つけられなくなり、次の読み込みでは古い名前で新しいデッキが作られます。
:::

Anki パッケージには独自のルール（[読み込みシート](#anki-report)での選択）があります。CSV ファイルは照合されることがありません。

## 書き出しと共有 {#export}

コレクションを持ち出すには、長押し（Mac では右クリック）して [アーカイブを書き出す]{.ui} を選びます。Mac では、**ファイル › Export Interest…**（⇧⌘E）で選択中のコレクションについて同じことができます。JustFlip! は *コレクション名*.flashcards.zip という 1 つのファイルを書き出し、保存先を尋ねます。

アーカイブには、そのコレクションのすべてが入っています。すべてのデッキとカード、画像と音声、そして**復習の進捗すべて**です。「ファイル」や iCloud Drive に保存したり、AirDrop で送ったり、ほかのファイルと同じように送信したりできます。

アーカイブを読み込むと、そのコレクションがそっくり元に戻ります。コレクション、デッキ、カードは、名前ではなくアーカイブに含まれる隠れた識別子で照合されるので、何も重複せず、名前を変えたデッキも見つかります。

::: gotcha
#### アーカイブはスケジュールも一緒に持ってきます

アーカイブを読み込むと、各カードのスケジュールはアーカイブに保存されたものに設定されます。学習中のコレクションに古いアーカイブを読み込むと、それらのカードは書き出した時点の状態に戻ります。復習の履歴は重複せずに統合されます。書き出しのあとに追加したカードは残り、書き出しのあとに削除したカードは戻ってきます。
:::

::: note
#### 誰かとデッキを共有する

アーカイブにはあなたの進捗も含まれていて、読み込んだ人はそれらのカードについてあなたのスケジュールを受け継ぎます。まっさらなコピーを渡したい場合は、代わりに元のデッキファイル（読み込んだ `.flashcards` や `.flashcards.zip`）を共有してください。
:::

同じメニューには、[スプレッドシート（CSV）]{.ui} または [完全データ（JSON）]{.ui} 形式の [統計を書き出す]{.ui} もあります。これらのファイルは閲覧や分析のためのもので、読み込み直すためのものではありません（第 9 章）。ライブラリ全体のバックアップについては第 10 章を参照してください。

## 読み込みで意外なことが起きたら {#troubleshooting .cheatsheet}

| 見えている現象 | 理由と対処 |
|---|---|
| 行数やノート数よりカードが少ない | 問題のテキストが同じカードが統合された（デッキファイル）、または問題が空の行がスキップされた（CSV） |
| Anki のノート数よりカードが多い | 穴埋めの番号ごとに 1 枚のカードになります。想定どおりです |
| デッキが 2 つできた | CSV は常に新しいデッキを作ります。[新しいコピーを追加]{.ui} での Anki の読み込みも新しいデッキを追加します |
| 画像だけのカードが 2 倍になった | 読み込み直しでは照合できません。余分なものを削除するか、新しいデッキに読み込んでください |
| 読み込んだカードが読み上げられない | Anki と CSV のカードには言語がありません。カードに言語を設定してください（第 3 章） |
| 最初のカードが「問題 / 答え」になっている | [最初の行をヘッダとしてスキップ]{.ui} をオンにします |
| すべてのテキストが 1 つの列に入っている | CSV のプレビューで [区切り文字]{.ui} を変更します |
| 画像が見当たらない | Anki のレポートを確認してください。SVG には対応していないことにも注意してください（第 4 章） |
| 読み込みのあと、自分の修正が消えた | ファイルの内容で置き換えられました。ファイルも修正してください |
| カードのスケジュールが巻き戻った | そのコレクションの古いアーカイブを読み込みました |
